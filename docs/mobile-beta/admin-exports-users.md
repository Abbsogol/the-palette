# Account details and administrative exports

8 October 2026: applied migration `202610080034_admin_user_directory.sql` to isolated beta `atjwbdrvgljddedtwoqo`; deployed the dashboard to `laque-beta` only.

Users & Creators searches name, username and authoritative sign-in email, with user/creator/salon filters. The directory includes contact, verification, setup and suspension status. Inspect groups identity/profile/media, account/privacy, related retained activity, creator services (up to 100) and working hours/time zone. Recent internal case notes remain available. Owner additionally sees sign-in provider/confirmation/last-sign-in/MFA-registration summary, credits, acceptance timestamps, account preferences, booking and health notes, and analytics preference. Support has a narrower projection and does not receive private preference/health/authentication/balance fields. There are no passwords, token/MFA secrets, full authentication metadata, provider payment identifiers, conversations or private Lab image gallery.

Exports: Owner-only filtered user directory CSV across pages; Owner-only individual account detail JSON; role-scoped operational table CSV; role-scoped Overview aggregate JSON for the selected 7/30-day range. No unrestricted table or column selector exists. Filters match the current view. Multi-page exports are bounded at 5,000 rows and 4 MiB; oversized exports ask for narrower filters and do not silently truncate. Case details JSON includes the same bounded service/note views as Inspect, rather than a raw database backup.

Every export requires a 5–1,000-character purpose, verifies Supabase/AAL2/verified authenticator/active current staff, rechecks identity after assembly, and logs through an atomic service-only role-checking function before any response is delivered. Revoked or downgraded staff cannot complete a download. Only the Owner can export users, including account-detail JSON; Support cannot bypass this with direct API calls. The audit stores section, record count, actor and reason, not exported contents or authentication tokens. Responses are private/no-store attachments. CSV quotes cells and neutralizes spreadsheet formula prefixes. No new paid platform is used.
