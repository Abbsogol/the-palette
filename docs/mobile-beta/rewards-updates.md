# Official Updates and Rewards — 9 October 2026

## Product flow

Home → Explore now has **LaQue / Pinterest / Competition** source tabs above the design filters. LaQue keeps its existing category/sort controls and includes a recent competition-design section; Competition opens the complete, paginated entry gallery directly. Pinterest opens the existing attributed inspiration collection. Its own topics/loaded-selection filters remain separate from LaQue's saved-design ranking.

Competition submission automatically makes an eligible entry discoverable on Home; no second publication action or copied design is required. The Home feed orders entries newest first, with UUID tie-breaking and 25-item pages. It reuses server-controlled country, reviewed publication, author privacy, blocking, deletion and moderation checks. Refresh/open/foreground refresh clears unavailable entries. Competition votes are available on each Home card using the existing idempotent vote endpoint; self-votes, paused/closed rounds and inactive prize participation remain blocked. Tapping the image opens the existing design detail, including Share with my nail tech; the round label opens that competition. The entry action opens Updates → Rewards directly.

Home → Updates contains **News** and **Rewards**. This adds no bottom tab. News is published by currently assigned Owner/Moderator staff using Admin Studio; members post personal content in Community. The retired `/updates/new` link explains the change and links to Community. Existing published Home announcements appear inside News.

Rewards lists only published rounds for the member's saved profile country, or worldwide rounds. The profile country is private, self-declared information entered in Edit profile → Profile country. It does not use GPS or prove residence. A member without a country sees worldwide rounds only. Server checks apply to lists, direct/shared links, entry submission and voting. Admin Studio can inspect every region and filter by country.

A round shows the theme, prize type/pool/allocation, entry/voting/award deadlines, rules, participant designs, entry checklist and results. Entry requires a verified account, completed public profile with age/privacy acceptance, and a current verified Lab entitlement. Entrants select at most three existing confirmed, published Lab designs and explicitly accept the current rules. The server requires generation ownership and a completed reservation; uploaded photos and unconfirmed generations do not qualify. No extra AI call, generation credit, entry fee or referral requirement is introduced. Paid store configuration remains a separate existing billing prerequisite.

Submitted images use the confirmed Lab original. Submitted design metadata/images lock; authors retain unpublish/delete and privacy rights. Those actions remove the public entry and do not replenish a consumed entry slot. Lost-response replay of the same design returns the original entry. Duplicate aliases of the same generation cannot create extra slots. Candidates currently show the most recent 50 published eligible Lab designs.

Verified members can vote without a subscription. Votes are separate from ordinary design likes, explicit set/unset and one per account per entry. Self-voting is blocked. Suspended/closed voters are excluded. This is not a guarantee against multiple verified accounts, collusion or vote fraud; staff must review before awards. Invitations are optional, and the flow does not require Google as the only account provider.

External sharing links preserve the selected entry through sign-in. The generic web landing exposes no competition/design metadata to signed-out users; regional checks apply after sign-in. It offers a `laque://` app link. Real universal-link/store-install routing and two-device sharing still need acceptance testing with signed builds.

## Admin Studio

**Official Updates**: searchable/paginated list, worldwide or selected country audience, draft/edit/preview, explicit publish/archive. There is no mobile member publishing action.

**Rewards**: searchable/paginated list across all regions, theme/details/prize types (cash, products, gift cards/codes), UTC-backed deadlines displayed in the editor's local time, winner count, country targeting, rules, draft/preview, Owner review evidence, publish/pause/resume/archive. Submitted designs can be inspected with short-lived original previews and valid vote counts; moderation can disqualify/restore entries with reasons. Private, closed, suspended or unpublished authors' Lab originals are unavailable in this review, and there is no unrestricted generation gallery.

Existing MFA/current staff permissions apply. Support and ordinary members cannot manage either section. Every administrative mutation rechecks membership, requires a reason, rejects stale versions and records an action atomically. Published rules/targeting cannot be edited; create a new draft for a materially different round.

Results are explicitly published by Owner after voting closes, selecting the highest valid votes. **Defaults:** one winning design per entrant; ties use earlier entry time, then UUID. The number of eligible distinct entrants must meet the published winner count, otherwise the transaction rolls back for resolution under the rules. These mechanics must be disclosed in the final official rules. Results freeze counts, and eligible public winner profiles are promoted for 30 days. Hidden/deleted/private winners do not remain visible. No automatic prize payment, gift-code disclosure or fulfilment is implemented; fulfilment is manual under the reviewed rules.
